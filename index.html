Overview

The Jonair Performance EFB is a digital performance tool for King Air 200 (BE20), Beechcraft 1900C (B190) and Cessna Citation 560XL (C56X). All calculations are performed locally on the unit using the aircraft's verified performance engine — no data is sent to any server.

The app operates fully offline once installed as a PWA (Progressive Web App). Performance data is based on EASA Performance Class A regulations.

Your last-used tab, form inputs, airport selections and most recently fetched METARs are saved locally and restored on your next visit.

📡 Internet required for: Fetching live METAR data and checking for app updates. All performance calculations work without an internet connection.

Settings & Custom Airports

Open Settings with the gear icon in the header.

  • Check for updates and install — checks for a new app version. Updates are also checked when the app starts.
  • User Guide — opens this guide.
  • Custom Airport — a checkbox that replaces the built-in airport database with your own runways.

Custom Airport

⚠️ Emergency / diversion use only: Custom Airport is meant for emergencies and unplanned situations, not for planned flights. For planned flights, ask the admin to add the airport to the airport database in advance. Stored custom airports can be removed at any time.
Turning it on
Tick Custom Airport (overrides airport database). While it is ticked only your own runways are used and the built-in database is ignored. Untick it to return to the built-in database. Your custom runways are kept when you untick it.
Edit custom airports
The button appears under the checkbox when Custom Airport is on. It opens a form with these fields, which you enter manually: ICAO, RWY, RWY Elev [ft], TORA, TODA, ASDA and LDA [m], Slope [%], RWY HDG [°] and Min climb gradient OEI [%]. The checkbox Engine out climb path: Turning sets the climb path to Turning; unticked means Straight. Press Save runway to store it. Saving an ICAO + RWY that already exists replaces that runway. Saved runways are listed below the form: Edit loads a runway into the form (change it and save again) and Delete removes it. The form does not open by itself — press Edit custom airports, which appears under the toggle when it is on. One runway is one entry, so enter each runway direction you need separately. Custom airports are used on both the Take-off and Landing tabs.
METAR
METAR fetching works for custom airports too, as long as the ICAO code is correct (a real 4-letter code that has a METAR). With an invented or wrong code the METAR turns red — enter the weather manually.
How you know it is active
A CUSTOM badge is shown in the ICAO field on both the Take-off and Landing tabs whenever a custom airport is in use. Always check for it before relying on the numbers.
Where the data is stored
Custom runways and the checkbox state are stored only on this device, in the browser or PWA storage. They are not sent anywhere and are not shared between devices. Installing an app update does not remove them. They are lost if you clear the site data, delete the PWA, or reset Safari website data.
⚠️ Verify custom data: The performance calculations trust the values you enter. Double-check elevation, slope, runway heading and declared distances against the current AIP.

ForeFlight Button

The ForeFlight button in the header opens the ForeFlight app on the same device.

  • It works only if ForeFlight is installed on the device. On a PC or laptop nothing happens or the browser shows an error.
  • The EFB stays open in the background, so your inputs and results are still there when you return.
  • No data is transferred between the apps. Airport, runway and weather are not sent to ForeFlight.

Take-off Tab

Calculates EASA Performance Class A take-off distances and associated speeds for the selected aircraft, airport, runway and conditions.

Airport & Weather Card

ICAO
Type the 4-letter ICAO code of the departure airport. An autocomplete list appears — only airports in the built-in database are available. Press Enter or tap a suggestion to confirm.
RWY
Select the intended take-off runway from the dropdown. Only runways with performance data for the selected airport are shown.
Runway suggestion
After a METAR is fetched, an amber message can appear below the runway fields: "METAR suggests RWY xx (n kt headwind). Verify before use." The runway with the largest headwind component is suggested. Each option lists the available distances and a Use RWY button that selects the runway (and intersection) for you. For take-off, an option that does not fit the current setup is marked unavailable with the reasons and the button is disabled. No suggestion is given when the wind is calm, variable (VRB), no runway has a headwind, or two runways have almost the same headwind — select the runway manually. The suggestion is only a hint based on the METAR wind; it never replaces the pilot's own runway decision.
Intersection
Appears only when the runway has a defined intersection departure point. Selecting an intersection uses the reduced TORA/TODA/ASDA for that intersection.
METAR
Displays the most recently fetched METAR. Colour coding:
  • Green — less than 35 minutes old
  • Amber — 35–60 minutes old (use with caution)
  • Red — unavailable or older than 60 minutes
When a valid METAR loads, Wind Direction, Wind Spd, OAT and QNH are filled automatically. Press Update to manually re-fetch.
Wind Direction (°)
Wind direction in degrees magnetic from the METAR or entered manually. Used to compute headwind/tailwind and crosswind components.
Wind Spd (kt)
Mean wind speed in knots. If the METAR reports a gust, only the mean speed is inserted — consider entering the gust value manually for a conservative crosswind assessment.
OAT °C
Outside Air Temperature at aerodrome elevation. Affects density altitude and all performance distances.
QNH (hPa)
Altimeter setting in hPa.

Setup & Mass Card

Take-off Mass (lbs)
Use the slider to set planned take-off mass. Ranges: BE20 9,200–12,500 lbs | B190 10,000–16,600 lbs | C56X 13,500–20,000 lbs. The mass is displayed above the slider and updates live. Change its touch target size under Settings.
Flaps setting
  • Flaps Up — standard configuration (all types)
  • Approach — all types; typically used when field length is limiting
  • Take-off — B190 only; intermediate setting between Up and Approach
  • Flaps 7° / Flaps 15° — C56X only (replaces Up/Approach). Flaps 7° is recommended with deice fluid.
Different flap settings yield different V-speeds and distances.
Take-off technique (B190 only)
Static T/O power (brakes held, full power set before brake release) or Rolling take off. Affects TOR, TOD and ASD.
Engine Anti-Ice
ON or OFF. Enabling anti-ice reduces available power, however if max torque can be achieved with engine anti-ice ON, this setting can still be OFF. Increasing all distances and reducing OEI climb gradient. Icing conditions may mandate ON.
Runway Condition Code (RWCC)
Always obtain the current code from ATIS/SNOWTAM/ATC. Actual contaminant type and depth is not used in the takeoff calculations — only the RWCC is used to determine performance penalties (factors are verified).
Reversers — Available / INOP (C56X only)
Select Available or INOP. Reversers are not credited in the C56X take-off distance calculation, which uses the dry field-length chart and applies the selected RWCC factor.
Deice fluid — Type II/III/IV applied (C56X only)
Set to YES when Type II, III or IV anti-icing fluid has been applied. Per AFM, take-off field length on dry, wet and contaminated runways is multiplied by 1.15; Flaps 7° is recommended. Type I fluid needs no correction — leave on NO.
Max take-off mass, current setup
The card under the mass slider shows the highest mass (50 lb steps) that satisfies all take-off limits for the current airport, runway, weather, flaps, anti-ice, RWCC (and for C56X reversers and deice): TORA/TODA/ASDA, OEI climb gradient and speeds. It also shows the margin to the selected mass (green = selected mass OK, red = exceeds). It does not move the slider. "Not available" or "None" means no mass in range fits, or an input is missing.

Take-off Result Cards

V1 / VR / V2
Decision speed, rotation speed and take-off safety speed (KIAS). For C56X, V1 includes the runway-gradient correction; the next more conservative published slope step is used where applicable, and downhill uses the SHADED correction. Use these values for the briefed conditions. Never depart with a different mass or configuration.
Takeoff distances
Within limits — all of TOR, TOD and ASD fit within the runway. Exceeded — at least one limit is breached. Take-off must not proceed. For C56X the text shows how the distance is built, e.g. TKOF 1,633 m (1.11 perf × 1.11 RWCC × 1.00 fluid = 1.23) · Within limits: dry-chart distance × performance factor × RWCC factor × deice-fluid factor.
Climb gradient OEI / Req
Calculated OEI climb gradient vs. minimum required (from obstacle / SID data in the airport database). For C56X, the AFM correction for turning climb up to 15° bank is applied only for turning climbs (airport column Engine out climb path = Turning, or missing, shown in amber): take-off mass is multiplied by 1.035 at or below 19,323 lbs; above that, 1.2 percentage points are subtracted from the gradient. Straight-out departures use the chart value unchanged. The card shows which climb path was used. If actual < required, the card turns red — take-off cannot legally proceed. The "Req" field is taken from the airport database (min climb gradient OEI).
WIND | XW (XWLimit)
Headwind (+) / tailwind (−), crosswind, and crosswind limit. Red = crosswind limit exceeded or tailwind above 10 kt. Amber = tailwind of 10 kt or less (card turns amber) — allowed but increases distances, so check the result carefully. Any tailwind always increases distances.
EMG RETURN — VREF / LD
Reference speeds and distances for an emergency return landing on the departure runway. UP = flaps up, DOWN = flaps down. Use to verify an emergency return is feasible given the available LDA.

EASA Class A Checklist

Five compliance items checked automatically:

  1. TOR ≤ TORA
  2. ASD ≤ ASDA
  3. TOD ≤ TODA
  4. Single value of V1
  5. Wet/contaminated runway mass limit

Any FAIL means the take-off must not proceed as planned — reduce mass, select another runway, or wait for improved conditions.

Landing Tab

Calculates required landing distances under EASA CAT rules.

Airport & Weather Card

Identical fields to the Take-off tab, but for the destination airport and arrival conditions. The landing ICAO/runway are stored independently from the take-off values.

Setup & Mass Card

Landing Mass (lbs)
Expected landing mass. Ranges: BE20 9,000–12,500 lbs | B190 10,000–16,600 lbs | C56X 13,000–20,000 lbs (see C56X Landing below). Above 16,100 lbs (B190 maximum design landing weight) the mass is shown in red with an emergency-use-only warning. Change its touch target size under Settings.
Flaps setting
UP or DOWN (BE20/B190). Both Vref and distance are calculated for both settings simultaneously. The selected setting determines which distance is compared against LDA in the exceedance card. C56X has no selection — landing flaps are fixed at 35°.
Runway Condition Code (RWCC)
Same GRF code applied to the landing runway. A lower code significantly increases required landing distance.

Landing Result Cards

VREF / FLAPS [setting]
Reference landing speed for the selected flap setting.
Landing distance
Within limits or Exceeded vs LDA. If flaps UP is exceeded, try flaps DOWN. If both exceed, the approach must not be commenced.
Missed App Climb gradient OEI
OEI missed approach climb gradient. EASA minimum is 2.5%. If below, the card turns red — an instrument approach may not be legal. Check the specific procedure minima and Operations Manual.

C56X (SE-RIJ) Landing

Landing performance follows the AFM landing procedure (Flaps 35, Figures 4-43 to 4-50) and is calculated directly from the C56X performance database.

Landing Mass (lbs)
13,000–20,000 lbs. Normal landings are limited to 18,700 lbs. Performance above 18,700 lbs is provided as additional information for an emergency that requires landing above the maximum design landing weight. A red warning is shown above 18,700 lbs — emergency use only.
Flaps / Anti-ice
Landing flaps are fixed at 35°. Anti-ice ON/OFF selects the applicable approach and landing climb charts. With anti-ice ON, the maximum landing weight is the lesser of the Figure 4-42 climb limit and Figure 4-43 brake-energy limit.
Reversers — Available / INOP
Default Available. Selecting INOP uses the higher no-reversers runway condition factors, increasing the required landing distance.
Required distance
AFM landing distance (Figure 4-44 for level or uphill runways, 4-45/4-46 for 1% and 2% downhill) multiplied by the runway condition factor and compared with LDA.
Approach / Landing climb gradient
Gross approach climb (Flaps 15, minimum 2.5%) and landing climb (Flaps 35, minimum 3.2%). The card turns red if either is below its minimum.
VREF (50 ft) / VAPP
Reference speeds from the Flaps 35 landing charts, based on landing mass and pressure altitude. Values between published points are linearly interpolated.

METAR & Weather Input

METARs are fetched automatically when a new airport is selected, and on demand via the Update button.

⚠️ Manual override: Manually edited weather fields (Wind Direction, Wind Spd, OAT, QNH) will be overwritten by the next METAR fetch. Re-enter them afterwards if needed.
  • Gusts: Only mean wind speed is extracted. Enter the gust speed manually for a conservative crosswind check.
  • VRB winds: Treated as 0° direction — assess crosswind manually.
  • Age limit: METARs older than 60 minutes are rejected. For actual operations always verify with the latest ATIS/D-ATIS.
⚠️ METAR not working? Check that the iPad has an internet connection, and that date and time are correct (Settings → General → Date & Time → Set Automatically). The METAR age is calculated from the device clock, so a wrong date or time makes a fresh METAR look old and it is rejected.

Runway Visualization

A schematic runway graphic appears in both tabs:

  • The coloured bar inside the runway shows the worst-case calculated distance as a proportion of the available runway (TORA / LDA).
  • Markers (take-off only) indicate TOR, TOD and ASD distances to scale. The value is shown in the marker label.
  • The bar turns red when any distance exceeds the limit.
  • Landing shows two markers: amber (flaps UP distance) and green (flaps DOWN distance). For C56X a single marker shows the required (factored) landing distance.
The visualization is a schematic aid only. Always use the numerical values for operational decisions.

The graphic updates live: the bar and markers slide to their new position whenever airport, runway, weather or setup changes. The runway suggestion in the Airport & Weather card (see Airport & Weather, Runway suggestion) is based on the METAR headwind component per runway.

Saved Data

The app stores your inputs on this device so they are there when you reopen it:

  • Airport & Weather and Setup & Mass cards on both the Take-off and Landing tabs: airport, runway, intersection, wind, OAT, QNH, mass, flaps, anti-ice, RWCC, reversers and deice are saved separately per aircraft type.
  • The last METAR for each airport is kept, and its age is recalculated on restore (so it turns amber/red as time passes).
  • Selected registration, active tab, and custom airports.

Data stays on the device only. Clearing Safari website data or deleting the app removes it.

Install & Offline Use

Install on iPad / iPhone

  1. Open the app address in Safari.
  2. Tap the Share button → Add to Home Screen → Add.
  3. Start the app from the new home-screen icon. It opens full-screen like a normal app.

On a PC or laptop, Chrome/Edge show an install icon in the address bar. The app can also be used directly in the browser.

Offline use

  • The first time the app is opened with internet, all app files and performance data are stored on the device. After that the calculations work without internet.
  • Open the app once online after installing or updating, before relying on it offline (for example before a flight).
  • Offline, METAR fetching does not work. Enter wind, OAT and QNH manually. The last saved METAR for an airport is still shown with its age.

Updates

Use Settings → Check for updates and install (internet needed). After installing, close and re-launch the app. Your saved inputs and custom airports are kept.

If the app looks outdated or fails to start offline, open it once with internet and run the update check.

Runway Condition Code (GRF/RWCC)

The Global Reporting Format defines 6 runway condition codes. Obtain the current code from ATIS, SNOWTAM or ATC.

Engine Out Procedure Card

Shown at the top of the Take-off tab for the selected runway:

Escape Route
Published engine-out routing after V1 for the selected runway. May include headings, altitudes or waypoints. Brief this before every departure.

Common Pitfalls & Errors

All results show "–" or "FAIL"
The performance database has not loaded yet, or no valid ICAO/runway combination is selected. Ensure a valid airport and runway are set and wait for results to populate.
METAR shows red immediately
Airport not found in NOAA's database, no internet, or the device date/time is wrong. Check the connection and that the iPad date and time are set automatically. Otherwise enter weather values manually.
V1 shows "–" but other speeds appear
Mass or conditions may be outside the performance table range. Try reducing mass, or verify that OAT and QNH are within bounds.
Crosswind shows "–"
Wind direction or speed is not set. Fetch a METAR or enter values manually.
Climb gradient shows "–"
The minimum OEI climb gradient is empty for this runway. Verify the required gradient manually from the applicable SID or obstacle clearance procedure.
Aircraft type change warning
You are switching between BE20 and B190. Confirm only if intentional. The entire workbook is replaced and all previously calculated values change.
App shows old data after an update
Settings → Check for updates → Install update. On iOS, close and re-launch the app after updating.
